### Description:
This code creates a loadings plot and a scores plot from pca analysis results 
that were provided.
This is for ms2 of Excalibur project.

### How to proceed:
1. Open the project folder in R/RStudio.
2. Run main.R.

### Notes:
- main.R runs renv::restore() on its firts line. 
- If you want to run the analyses separately, run the helpers before any other
scripts.
